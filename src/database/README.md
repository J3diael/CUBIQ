# database

SQLite storage. `open.ts` opens the device database and runs migrations at startup, `client.ts` holds the open database, `schema/` defines the Drizzle tables, `migrations/` holds the SQL generated by `npm run db:generate` (committed, never edited by hand), and `repositories/` exposes typed read/write functions. `test-utils.ts` creates a real in-memory database for Jest. Screens read through repositories (via `useDbQuery`) and write through the data store; they never contain SQL.
