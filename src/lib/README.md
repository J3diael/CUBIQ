# lib

Pure TypeScript with no React, database or native imports, so everything here is unit tested with plain Jest.

- `time/` formatting and parsing of durations (milliseconds in, strings out)
- `statistics/` Ao3/Ao5/Ao12, means and personal bests (Phase 4)
- `timer/` timer state machine (Phase 2)
- `cubing/` scramble service and cube state for diagrams (Phase 2)
- `validation/` Zod schemas
