# lib

Pure TypeScript with no React, database or native imports, so everything here is unit tested with plain Jest.

- `time/` formatting and parsing of durations and dates (milliseconds in, strings out)
- `stats/` Ao3/Ao5/Ao12, means and personal bests
- `timer/` timer state machine
- `cube/` 3x3 sticker model, move notation and diagram data for algorithms and lessons
- `training/` spaced-repetition schedule and mastery for flashcards
- `goals/` goal targets, titles and progress
